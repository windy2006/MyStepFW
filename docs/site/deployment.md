# 部署与入口参考

目标运行环境：PHP 7.4。本文提供通用部署示例，具体域名、证书、PHP服务地址及数据库凭据由部署环境自行配置，网站运行配置不随源码发布。

## 部署方式

网站根目录指向包含index.php的框架目录，动态请求交给统一入口；仅开放必要的公共资源。NginX、.htaccess和web.config分别提供相应服务器的配置参考。可按环境使用地址重写、路径信息或查询字符串路由。

## 应用及域名示例

可以将后台、CMS、示例和文档应用分别绑定到自己的域名；绑定关系保存在本机config/domain.php，不直接复制其他站点的绑定表。子目录部署应检查ROOT_WEB及资源地址，PHP服务端口、证书和文件权限应匹配实际环境。

| 入口 | 作用 |
| --- | --- |
| `/Admin/` | 新管理后台，与原后台共用框架配置与认证机制 |
| `/console/` | 原管理后台，名称由应用配置决定 |
| `/admin_cms/` | CMS后台，名称由CMS配置决定 |
| `/api/` | 已登记的应用或插件接口 |
| `/Document/`、`/Sample/`、`/test/` | 功能类说明、应用示例及执行流程演示 |

域名绑定改变路由上下文；强制绑定跳转、查询参数和请求方法的处理规则见[执行流程](../framework/execution.md)。

## 入口补充

Admin 位于 app/Admin，独立入口 /Admin/，与原后台并存。应用目录和框架规则说明统一见 [应用规范](../../app/README.md)、[执行流程](../framework/execution.md) 与 [Admin](../applications/Admin.md)。

## 站点文件访问保护

本机部署同时在 Web 服务和框架文件出口限制隐藏文件、私有配置、源码目录、注册表及非公共缓存；只允许统一 PHP 入口执行。迁移时须重新检查这些规则，不能仅依赖 try_files。具体请求与文件边界见 [执行流程](../framework/execution.md) 及 [请求安全](../framework/security-attachments.md)。
