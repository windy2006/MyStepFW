# 后台布局

说明插件管理页如何选择宿主外观，并保持独立的模板和安全校验。

## 7.3 通用后台布局

需要管理页的插件使用通用插件页面机制，宿主根据允许的应用信息及来源确定；来源为空时默认 myStep，不能把任意 Referer 当作可加载的模板路径。Admin、myStep 和符合约定的应用可提供自己的 `plugin_layout.php`／相应适配，插件保留自己的主体模板。

Referer 只帮助选择外观，管理员校验、CSRF 和业务权限单独执行。页面内表单、返回链接及 AJAX 地址使用 `pluginPageURL()`／`pluginAdminURL()` 等现有辅助入口，避免切换宿主后又跳回固定旧后台。详见插件规范的后台通用布局部分。
