## 主要用法示例

```php
require_once LIB.'pinyin.php';
$abbr = '';
$text = pinyin('中国', $abbr);
// $text是按字典转换的拼音，$abbr是对应缩写；字典外字符沿当前实现处理。
```

## 声明与类职责

### pinyin

功能说明：拼音字典文件的自动加载标记类；实际转换由同文件全局函数提供

使用说明：
  1. 调用pinyin($str,$abbr)取得拼音数组；内部转为GBK并忽略不可表示字符，$abbr接收缩写。
  2. 字典覆盖范围有限，不保证多音字语义识别或未收录字符的拼音。

使用示例：
    $items = pinyin('中文', $abbr); // 返回拼音数组，并填写$abbr

### pinyinIdx

功能说明：获得某个字的拼音索引

```text
function pinyinIdx($idx);
```

| 参数 | 类型、默认值与含义 |
| --- | --- |
| `$idx` | int；ASCII字节值或GBK双字节组合的有符号索引值 |

**返回值**：string 字典命中的拼音；ASCII索引直接返回对应字符，字典范围外返回空串

调用形式：

```php
$result = pinyinIdx($idx);
```

定位：`lib/pinyin.php:47`。

### pinyin

功能说明：获取字符串拼音；表仅覆盖 GBK 汉字，明确忽略无法表示的 Emoji 等字符

调用示例：
    $parts = pinyin('中文', $abbr); // 拼音数组以及引用输出的首字母缩写

```text
function pinyin($str, &$abbr="");
```

| 参数 | 类型、默认值与含义 |
| --- | --- |
| `$str` | string；待转换文本，内部以忽略不可表示字符的方式转为GBK |
| `&$abbr` | string；引用输出：按有效拼音逐字提取的首字母串（默认：""） |

**返回值**：string[] 逐字拼音/ASCII字符的顺序列表；缩写通过abbr引用输出，无法转换的字符可能被忽略

调用形式：

```php
$result = pinyin($str, $abbr);
```

定位：`lib/pinyin.php:75`。
