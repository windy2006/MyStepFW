# 配置原子保存、版本比较与冲突

修订日期：2026-10-23。适用于当前框架。

## 本篇目标与调用场景

将配置从读取到后台编辑再到持久保存拆开，避免把每次读取变成写配置。

### 原子保存和并发冲突

保存先完整编码，再锁定同目录锁文件、写入同目录临时文件并原子替换；失败时保留原文件，并保留已有文件权限。新文件默认 0600。保存后使对应 OPcache 失效；不再因普通值更新反复删除未变化的配置结构。

保存原文件时比较加载时的内容摘要，检测其他请求已经保存的修改，冲突抛 RuntimeException，提示重新加载。需要明确覆盖时可使用第三个参数：

```php
$config->save();                  // 默认拒绝覆盖并发修改
$config->save('php', '', true);   // 调用方明确选择覆盖
```

保存到不同文件的导出不套用原文件的版本检查。JSON 编码失败、根节点不是数组/对象、无效格式和读取期间持续变动都会明确报错，避免写入空配置或陷入格式回退循环。JSON 文本要求有效 UTF-8，不猜测原编码。


## 操作步骤与注意事项

默认拒绝覆盖并发修改；新文件和已有文件权限、同目录临时文件、锁及OPcache按当前保存流程处理。多文件保存不因此成为整体事务。

## 主要方法：参数、返回和失败约定

### myConfig::save

功能说明：编码完整配置并原子保存，默认防止原文件被并发更新覆盖

先编码后写入，编码失败保留原文件。保存原文件时比较加载摘要，成功后更新本实例
版本；显式导出其他路径不套用原文件版本检查。新文件权限 0600，既有权限保留。


调用示例：
    try {
        $config->save();
    } catch (RuntimeException $error) {
        // 重新加载并处理写入或版本冲突
    }

```text
public function save($type='', $file = '', $overwrite = false);
```

| 参数说明 |
| --- |
| string $type php/ini/json 或已登记格式；空字符串沿用原扩展名（默认：''） |
| string $file 目标路径；空字符串保存原路径，切换格式时自动替换原扩展名（默认：''） |
| bool $overwrite true 明确允许覆盖原文件的并发修改；默认 false 拒绝丢失更新（默认：false） |

**返回**：int 写入的完整字节数

**异常**：InvalidArgumentException 格式未登记；UnexpectedValueException 编码器没有返回字符串（包括 JSON 编码失败）；RuntimeException 目标不合法、无法加锁/写入/替换或内容版本冲突；Throwable 自定义解析器、初始化/反射目标或受信执行文件产生的异常继续传递

## 明确调用示例

```php
// $file指向临时配置文件，内容为return ['web'=>['title'=>'原名']];
$config = new myConfig($file);
assert($config->value('web.title') === '原名');
$config->merge(['web' => ['title' => '新名']]);
$config->save('php');
assert((include $file)['web']['title'] === '新名');
```
