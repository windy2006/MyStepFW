# init：类加载、预算与安装

## 本篇目标与调用场景

按当前源码的条件与顺序说明本阶段；特别标明哪些分支会提前结束，哪些变量和钩子尚未可用。

## 4. 基础初始化：myStep::init()

### 4.1 输出缓冲与类加载

初始化先调整输出缓冲，再读取 `config/class.php` 中的类加载路径和索引。

- 索引有效：直接向框架类加载器注册。
- 索引缺失、为空、结构/语法损坏，或首项根路径与当前 `LIB` 不一致：建立核心类库和数据库驱动搜索路径，原子重写类索引，注册加载器，并清理路由编译文件及模板编译目录。

注册类加载器后，Web请求先执行 `mySecurity::guardRequest()` 检查已解析输入及声明体积，再进行上述路由/模板缓存清理；拒绝时以400/413固定JSON结束，不启动应用或会话。CLI/phpdbg跳过。PHP本身可能已解析请求，不能把此检查当作运行时漏洞修复；类索引的必要加载和重建仍早于该检查。额度、覆盖方法及解析前部署要求见 [PHP运行时加固](../security/input-budget.md)。

重建操作只处理索引与编译产物，不删除现有 Session 数据。

之后计算 `ROOT_WEB`。它代表站点入口对应的 Web 路径，例如 `/` 或 `/sub/`，与磁盘路径 `ROOT` 不是同一种值。

### 4.2 初始错误处理

此时尚未选定请求承接对象，也未启动登录和数据库服务。框架先注册基础异常处理，将日志目标设为根目录的 `error.log`。进入完整 `start()` 后，会依据运行配置重新设置错误级别与回调行为。

### 4.3 安装分支与正常分支

| 条件 | 下一步 |
| --- | --- |
| 存在 `config/config.php` | 调用 `myStep::go()` |
| 缺少全局配置 | 对允许的静态文件安全输出，否则进入框架自带安装初始化入口 |

安装分支仍会检查静态目录边界和真实文件扩展名，不因为配置尚未生成而放开任意文件读取。

API全局参数由config/config.php的api分组提供默认补齐；专属域名按请求提供虚拟API前缀，不改域名绑定文件。API路由在应用启动前准备逐接口CORS、所有格式正文预算和总开关检查，合法OPTIONS直接204结束；实际调用继续会话和CSRF，再执行逐接口设置和位置参数调用。详细规则见[API调用与后台管理](../api/api.md)。

## 14. 通用排查顺序

1. 确认请求是否到达 `index.php`。Web 服务的文件命中、拒绝或跳转都可能发生在 PHP 之前。
2. 核对 `ROOT_WEB`、SCRIPT_NAME、PATH_INFO、REQUEST_URI 和 QUERY_STRING，判断输入采用哪种 URL 模式。
3. 核对 `route['p']`、`route['q']` 和初步 `info`，避免把参数问题误判为规则问题。
4. 检查域名虚拟前缀，以及原路径第一轮是否已被某条通用规则命中。
5. 检查路由源、分组顺序、格式作用域和生成表校验；不要仅修改生成文件。
6. 检查规则命中后的 `$info_app`、配置合并、核心选择以及域名跳转。
7. 检查认证是否恢复、中间件是否返回严格 `false`，以及回调签名是否符合参数约定。
8. 区分 `getModule()` 文件搜索、注册 `module()` 分发和普通入口自行解释路径。
9. 区分页面缓存、模板编译、资源缓存以及 API 缓冲覆盖；确认实际输出来自哪里。
10. 核对 HTTP 状态、Location、Content-Type、Content-Encoding 及错误日志，最后确认请求在哪个出口结束。

以上顺序只依赖框架机制，不依赖具体业务应用、具体插件或某个部署站点的配置。

路径设置统一按[路径配置规范](constants.md)处理：配置保存网站根相对路径，读取时由ROOT解析；类特别指定以该类目录为基准。类目录按网站根相对路径填写。

## 主要方法：参数、返回和失败约定

### myStep::init

功能说明：框架变量初始化

参数说明：无显式参数。

Web请求在类加载注册后、缓存清理和应用/会话启动前检查已解析输入预算；
PHP解析器已可能处理请求，此检查不能替代运行时补丁及Web服务器限制。

```text
public static function init();
```

**返回**：void 设置核心路径、配置、自动加载及请求上下文；超预算请求返回400/413并结束

**异常**：InvalidArgumentException 受信的MYSTEP_REQUEST_LIMITS配置无效；RuntimeException 无法完整发布类索引
