# 运行环境

## PHP环境

Web服务和命令行均使用PHP 8.5.12或更新的8.x版本。根据所用功能启用扩展，并在部署环境验证实际调用。

```bash
php -v
php --ini
php -m
```

- `mbstring`与`iconv`：字符集和多字节文本处理。
- `DOM`与`libxml`：文档解析和指南显示。
- `mysqli`、`sqlite3`或`sqlsrv`：按应用选择的数据库驱动启用。
- `openssl`或`sodium`：认证加密和HTTPS相关能力。
- `GD`：图片解码、缩略图及绘图。
- `fileinfo`与`zlib`：上传类型检查、压缩等功能。
- `redis`：使用Redis插件的缓存、会话或业务连接时启用。

以应用实际使用的驱动为准；命令行的扩展列表不能代替Web PHP的扩展检查。可在后台PHP信息页核对Web服务环境。

## 站点入口

将网站目录配置为Web根，启用所选URL模式的重写规则，确保根目录index.php可以正常接收请求。配置中的磁盘路径按网站根目录填写相对路径；浏览器URL使用框架地址生成接口。

运行账号需要能写入安装目录中的配置、缓存和上传目录。使用manager安装或更新文件时，按界面预检结果处理不可写的目标。

## 安装依赖

在项目根目录执行：

```bash
composer install
```

安装流程需要执行Composer脚本。若明确使用`--no-scripts`，应补充执行：

```bash
composer run php85-compat
```

命令失败时查看终端返回信息，确认依赖目录及目标文件可读写。

## 配置加载

应用设置通过myConfig读取。修改站点设置后刷新对应缓存；调整PHP配置或启用扩展后，重载Web PHP服务并重新核对PHP信息页。
