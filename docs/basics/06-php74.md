# 运行环境

## PHP与扩展

Web服务和命令行均使用PHP 7.4，最低7.4.0，版本须小于8.0.0。入口从`config/runtime.json`读取要求，Composer中的PHP约束为`^7.4`。在后台PHP信息页核对Web服务版本；终端命令检查的是命令行环境，两者分别确认。

```bash
php -v
php --ini
php -m
```

| 功能 | 所需能力 | 检查方式 |
| --- | --- | --- |
| 框架与文本 | JSON、mbstring、iconv | JSON配置解析、多字节文本及字符集转换 |
| 模板、XML和指南 | DOM、libxml | XML数据和Markdown正文解析 |
| MySQL数据库 | mysqli | `new myDb('MySQL', ...)`连接目标服务 |
| SQLite数据库 | sqlite3 | `new myDb('SQLite', ':memory:')`建立内存连接 |
| MSSQL数据库 | sqlsrv | 驱动、连接参数及数据库字符集按部署核对 |
| 字符串认证加密 | OpenSSL的AES-256-GCM | `myEncrypt::seal/open` |
| 文件认证加密 | Sodium的Secretstream | `myEncrypt::sealFile/openFile` |
| 图片 | GD及实际图片格式支持 | 按JPEG、PNG、WebP等所用格式核对 |
| 上传和压缩 | fileinfo、zlib | 类型检测、打包解包及压缩 |
| Redis插件 | phpredis扩展及Redis服务 | 插件检查、连接、认证和PING |
| Memcached插件 | memcached扩展及服务 | 按插件安装检查和实际读写结果确认 |

按功能启用扩展，不把MySQL、MSSQL、Redis等所有驱动都当作必装项。HTTPS访问还需要可用的证书信任链；邮件连接按实际使用的SMTP/TLS方式配置。

## 站点入口

网站根目录包含`index.php`、`lib/`、`app/`、`plugin/`、`config/`及`vendor/`。将此目录配置为Web根，按所选URL模式启用对应重写规则。静态资源可由Web服务器直接返回；动态请求交给根`index.php`。

框架设置里的磁盘路径使用网站根相对路径，程序通过`ROOT`及`myPath::absolute()`解析；浏览器URL通过`ROOT_WEB`和`myStep::setURL()`生成。类加载“特别指定”值相对于该加载规则的目录，见[路径规则](../backend/runtime/constants.md)。

## 依赖安装

在项目根目录使用同一PHP 7.4命令行环境执行：

```bash
composer install
composer check-platform-reqs
```

`composer.json`声明依赖范围，`composer.lock`记录本项目依赖版本。部署已有项目时按锁文件安装，并按实际加载结果检查`vendor/autoload.php`。只使用安装包已附带的完整依赖时，无需为打开页面重复安装。

## 可写位置

首次解包时PHP账号需要安装目录的写入和进入权限。运行期间按所用功能准备配置、缓存、会话和上传目录；manager替换源码时还需要对应目标及父目录的必要权限。安装器与更新器在写入前给出相对于站点根的失败路径，不自动修改账号所有权或放宽权限。

## 运行声明

`config/runtime.json`属于框架源码声明：

```json
{
  "format": 1,
  "channel": "php74",
  "php_min": "7.4.0",
  "php_max": "8.0.0"
}
```

`php_min`包含下限，`php_max`不包含上限。manager使用`php74`通道生成和检查包，更新源应提供同一通道。配置更新服务网址及安装更新的操作见[升级管理](../showcase/plugins/manager.md)。
