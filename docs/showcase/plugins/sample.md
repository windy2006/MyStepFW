# sample：插件机制演示

## 定位和适用场景

演示语言、模块、标签、start/page/end钩子、配置与编辑器扩展。安装时创建的示例目录是插件资源，不是每次请求必做工作。

## 当前目录及主要文件

源码位于`plugin/sample/`。以下为当前源码层级，不表示所有文件都会自动执行：

```text
plugin/sample/
├── class.php
├── config.php
├── config/
├── index.php
├── info.php
├── language/
├── module/
├── route.php
├── template/
```

## 入口与执行过程

index.php登记宿主功能；module/sample.php与template/sample.tpl展示后台；test1/test2为显式注册模块名。

## 配置、模板和资源

设置、语言、模板与asset/files等资源保持在本项目内；共用框架服务通过当前应用上下文调用。配置值与后台字段结构分别维护，表单客户端用checkForm，服务端仍校验权限、方法和CSRF。

## 使用步骤

1. 在测试站核对本项目目录、元信息和所需扩展。
2. 在插件管理中检查安装条件、安装／活动状态，选择所需应用绑定及运行顺序。
3. 先执行只读展示，再在独占测试资源中验证保存或管理动作。
4. 检查模板风格、窄屏、资源地址、会话与失败反馈；不在正式数据上试验安装或恢复。

## 边界与维护

示例包含注册名与文件名不一致的情况，说明框架按声明调用，不按目录名猜测。不要把演示接口默认为可公开写入。
