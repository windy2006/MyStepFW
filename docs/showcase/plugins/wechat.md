# wechat · 微信网页功能

网站在微信内打开时，插件按应用绑定动态注入微信官方JS-SDK，为页面提供分享、扫码、拍照、录音、定位等能力。普通浏览器保留原页面。

框架后台的插件设置可控制公众号账号、认证状态、允许来源、接口清单、分享内容、快捷按钮及微信专属HTML／初始化脚本。插件按照订阅号和服务号的条件过滤接口；微信服务器验证真实账号权限，客户端再检测是否支持。

凭证和票据由服务器缓存，浏览器只接收公开签名参数。支付和卡券只开放符合条件的SDK调用入口，业务订单及独立签名由应用实现。网页登录请使用相应的身份认证接入，不由本插件承担。

完整设置、接口列表和页面调用示例见 [wechat 使用说明](../../../plugin/wechat/README.md)。
