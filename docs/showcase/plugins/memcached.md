# Memcached

## 定位和适用场景

在符合条件的应用中通过memoryCache替换当前数据缓存，并把新的缓存引用同步给数据库查询缓存。

## 当前目录及主要文件

源码位于`plugin/memcached/`。以下为当前源码层级，不表示所有文件都会自动执行：

```text
plugin/memcached/
├── class.php
├── config.php
├── config/
├── index.php
├── info.php
├── language/
├── memoryCache.class.php
```

## 入口与执行过程

index.php检查扩展及宿主条件，加载插件自有memoryCache.class.php，使用myCache代理。

## 配置、模板和资源

设置、语言、模板与asset/files等资源保持在本项目内；共用框架服务通过当前应用上下文调用。配置值与后台字段结构分别维护，表单客户端用checkForm，服务端仍校验权限、方法和CSRF。

## 使用步骤

1. 在测试站核对本项目目录、元信息和所需扩展。
2. 在插件管理中检查安装条件、安装／活动状态，选择所需应用绑定及运行顺序。
3. 先执行只读展示，再在独占测试资源中验证保存或管理动作。
4. 检查模板风格、窄屏、资源地址、会话与失败反馈；不在正式数据上试验安装或恢复。

## 边界与维护

本插件无普通管理模板。服务连接、命名空间、TTL、存储错误需按适配器处理；不在初始化时flush共享服务。测试替身通过不等于真实服务已验证。
