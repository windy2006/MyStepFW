# Sample：路由与模板组合示例

修订日期：2026-10-23。现有应用介绍专栏。

## 定位和适用场景

演示自定义格式、显式规则、应用函数、接口和主子模板，便于理解框架运行对象。

## 当前目录及主要文件

源码位于`app/Sample/`。以下为当前源码层级，不表示所有文件都会自动执行：

```text
app/Sample/
├── config.php
├── index.php
├── info.php
├── lib.php
├── module/
├── plugin.php
├── route.php
├── template/
```

## 入口与执行过程

route.php声明mySample等示例入口及setting API；index.php装配主模板与sample子模板，业务函数来自lib.php。

## 配置、模板和资源

设置、语言、模板与asset/files等资源保持在本项目内；共用框架服务通过当前应用上下文调用。配置值与后台字段结构分别维护，表单客户端用checkForm，服务端仍校验权限、方法和CSRF。

## 使用步骤

1. 在测试站核对本项目目录、元信息和所需扩展。
2. 按已登记路由访问应用入口，并选择对应功能。
3. 先执行只读展示，再在独占测试资源中验证保存或管理动作。
4. 检查模板风格、窄屏、资源地址、会话与失败反馈；不在正式数据上试验安装或恢复。

## 边界与维护

模块与模板按功能对应。应用实例和数据作用域独立；此项目的专属目录、表结构或页面清单不自动成为其他应用的通用要求。
