# Sample、Document、test 示例应用

整理日期：2026-10-18。目标运行环境：PHP 7.4。这些说明只适用于相应示例应用，不作为框架所有请求的默认行为。

## 现有行为与边界

- Sample 的设置接口使用 `myConfig::get()` 导出，而不是从对象枚举结果中猜测 `setting` 层。公开副本递归移除数据库和口令、密钥、令牌等字段。
- Sample 页面不再修改运行中的真实设置来隐藏密码，也不再公开转储数据库/控制器内部属性；URL 诊断输出与配置展示进行 HTML 转义。
- Document 将已存在的示例文件名作为公开类反射白名单，直接访问数据库类文档时也注册数据库和缓存的加载路径。
- 邮件示例仅生成并展示 MIME，不在浏览文档时连接外部 SMTP 服务器发信。
- 配置示例的 GET 只修改内存；显式 POST 才导出演示 INI。
- 请求示例复用框架已有会话，不重新初始化请求对象或切换会话处理器，不显示完整 Cookie/Session；诊断值转义后显示。
- test 应用空模块和未知模块正确回退，保留模块设置的 `content`，列表内容链接通过框架生成；API 清理当前输出缓冲时不销毁上层缓冲。

## Document 模板兼容示例

扫描了应用、插件及示例中的 135 个 `.tpl` 文件，包含 120 个 loop、8 个 if、2 个 switch 和 1 个 random 标准块。所有文件均通过块结构检查及生成 PHP 的语法检查；检查没有执行这些模板中的业务查询。另搜索了 PHP 中的标签代码生成和开发文档示例。

switch 的两处现有模板为：

| 文件 | 原有结构与使用方式 | 处理结果 |
| --- | --- | --- |
| `app/Document/data/template/test.tpl` | `switch:start key='sw_show'`，使用 `(1)`、`(2)`、`(3)` 分支 | 保留原写法，分别验证三个值和未匹配值的渲染 |
| `app/Document/data/template/block_switch.tpl` | 无 key 的子模板，由 `app/Document/module/myTemplate.php` 的自定义标签通过 `getBlock` 提取 black/white/yellow 分支 | 保留原写法，验证分支映射，并在独立进程运行实际示例模块，覆盖三种颜色 |

应用和插件的现有模板中没有使用 `(default)` 分支；只有上轮新增的文档示例使用它作为默认分支。

## 开发示例的访问与维护

Document 中文件和压缩包示例仍可能写入示例目录，公开部署应单独限定访问范围。邮件示例不在浏览时投递外部邮件；仅凭编译或语法成功不能推断业务示例安全。注册模板语言与块语法统一见 [模板规范](../framework/templates.md)。

## 缓存示例的隔离范围

Document 的 myCache 演示使用独立短期文件缓存，不替换框架全局缓存，不操作真实 SQL 缓存表或清空共享 Memcached 服务；只清理本次演示数据。
