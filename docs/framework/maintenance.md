# 公共功能变更与调用同步

整理日期：2026-10-18。目标运行环境：PHP 7.4。变更公开契约时同批检查框架、应用、插件和示例。

## 每次修改应检查的范围

1. 用类名、方法名和方法别名搜索 lib、app、plugin、config、模板及可执行文档示例；动态代理和别名调用也需要跟踪到实际方法。
2. 对照调用上下文确认省略参数、null/false/0、返回类型和失败处理，不能只检查语法或声明文件。新增可选能力时，通过代理 supports 检查驱动声明，不以代理 instanceof 或 method_exists 猜测真实支持。
3. 检查初始化和后端切换后的对象挂接，尤其数据库查询缓存、会话和全局实例；依赖保存的旧对象引用须同步更新。
4. 检查后台清理、更新、卸载等维护入口是否仍直接操作已更改的存储布局；不能删除活动锁文件或把过期回收当成全量清空。
5. 同步类/方法注释、配置说明、可执行示例和兼容说明。保留可合理支持的旧约定；确需迁移时明确旧新用法。
6. 运行 PHP 7.4 下的专项测试和真实调用入口回归。并发、对象挂接或失败语义变化应有对应验证；测试写入使用临时目录和独立数据库。

## 兼容与清理

数据库及缓存可选能力使用 supports 检查，不能仅凭 method_exists 推断。旧接口签名保留；清理约定统一见 [缓存](cache.md)。具体应用／插件调用修复保留在各自维护文档，不在此重复复制。

## 2026-10-18 整体执行链复核

本轮沿真实入口和调用关系复核框架、应用与插件，不代表对所有第三方组件逐行证明。检索基线覆盖lib、app、plugin中596个PHP／模板／脚本／配置数据文件，重点复核myStep、myRouter、myController、插件公共接口、CMS初始化、新旧后台和前端资源契约。

### 当前流程与边界

```text
index.php → init：路径、自动加载、异常与输出缓冲
→ go：全局配置、应用前置、活动插件前置
→ 域名绑定、路由解析、公共资源出口
→ 合并应用配置、确定同名myStep子类或兼容回退
→ setPara/start：应用lib、资源、服务、Session、CSRF、登录
→ 绑定且启用的插件index.php、start钩子
→ 路由处理器／应用模块／模板输出
→ 正常收尾：end逆序钩子、shutdown、关闭数据库、输出
```

文件、API、重定向和报错等提前退出分支不一定经过正常end链路；应用代码不能把必须提交的业务事务或唯一清理动作只放在end钩子中。插件前置属于全局阶段，普通初始化与宿主绑定求交集，独立API以声明和活动状态为准。完整顺序见[执行文档](execution.md)，具体插件约定见[插件规范](../../plugin/README.md#15-生命周期一致性与独立-api)。

| 问题 | 修正与验证 |
| --- | --- |
| 插件API主类只能依赖宿主绑定间接加载，换core或未绑定时返回模块缺失 | 以活动API表为前提按需加载标准class.php，不额外运行index.php；验证默认宿主、独立core及停用后不加载 |

| 新旧后台启停分开读取与写入，可能丢失并发切换 | 状态在simpleDB单次mutate中读取并切换，异常时关闭连接 |
| 旧后台空标识可打包整个插件根目录，且manager未加载时可能导出在线配置；打包脱敏直接作用于在线目录 | 新旧后台共用buildPluginPackage，拒绝空标识，独立副本脱敏并过滤约定的配置／运行数据；验证有／无manager时的包内容和在线文件保留 |
| 公开上传设置直接intval解析INI，K/G单位和无限制值导致前端上限误报 | 按字节统一取正限制，再以MB保留max_size，并提供max_size_bytes；验证512K、G单位、单项无限制和双项无限制，现有上传组件支持小数MB |

所有新增公共函数、参数、返回值、异常及闭包都补充了原有格式的说明；应用专属代码仍留在各自app目录。正式插件注册表、启用状态、配置与业务数据未通过测试安装／卸载／清空。

### manager更新权限预检（2026-10-18）

补齐实际更新成员之外的备份目录、配置及配置锁、文件校验清单、本地缓存目录和分片锁权限检查；递归删除先检查所有目录，备份前检查旧内容可读。删除文件要求父目录可写，文件自身只读不再误判为不可删除。已知权限不满足时，在替换源码前返回相对路径错误，不自动修改权限。校验清单生成器也确认实际写入字节数，避免保存失败仍返回成功。

权限授权必须针对Web PHP实际运行账号；只下载更新包与在线／上传离线包执行更新的权限要求不同。详细路径与部署方式见[插件编写规范中的更新权限说明](../../plugin/README.md#更新所需的php文件权限)。预检不保证并发权限变化、迁移副作用及外部缓存服务可用，也不改变原有整体恢复边界。
