# 打包与更新（manager） <small>v1.1.9</small>

## 功能概述

检查框架、应用及插件版本，进行在线或离线更新、文件校验和安装打包。

## 安装与设置

安装启用后从manager/进入。先设置更新网址，再检查版本；更新前备份代码与数据。在线更新读取相同运行通道的更新源；离线更新上传manager生成的更新包。更新时程序检查目标路径、写权限及包格式并反馈失败原因。

## 设置说明

安装／设置页的“填写说明”会在独立插件指南中打开本文件对应章节。所有示例均为示范值，请按实际环境填写；不要复制示例密钥作为生产凭据。配置保存在本插件的 `config.php`。

### setting-pack

**开启打包**（`pack`）

是否开启框架整站打包入口。该入口始终要求框架管理员登录；在非调试环境关闭后不能一键打包当前框架。

示例：

```text
false
```

### setting-update_url

**更新网址**（`update_url`）

更新服务器域名或HTTP/HTTPS基址，不填写/api/plugin_manager/。省略协议采用HTTPS，不自动降级；明确使用HTTP时写出http://。留空只进行离线更新；更新源需要与本机运行通道一致。

示例：

```text
https://updates.example.com
```

### setting-update

**开启更新**（`update`）

是否把本站作为更新服务器向其他框架站提供版本及更新内容。这不是本站接收在线更新的总开关；作为普通客户端时可以关闭。

示例：

```text
false
```
