# 插件示例（sample） <small>v1.0.1</small>

## 功能概述

展示安装、卸载、路由、菜单、模板、页面钩子、API及不同配置控件的用法。

## 安装与设置

安装建立dir1、dir2演示目录并登记路由和菜单；将插件绑定测试应用可观察页面标题前缀。卸载清理演示目录与登记项。演示API仅返回公开设置，不返回密码字段。用于学习时参考class.php、index.php、route.php、module及template。

## 设置说明

安装／设置页的“填写说明”会在独立插件指南中打开本文件对应章节。所有示例均为示范值，请按实际环境填写；不要复制示例密钥作为生产凭据。配置保存在本插件的 `config.php`。

### setting-para_1

**文本测试**（`para_1`）

文本输入和name格式校验示例，最多50字符，不使用特殊符号。

示例：

```text
DemoName
```

### setting-para_2

**数字测试**（`para_2`）

实数输入示例，最多10字符，允许合法小数。

示例：

```text
12.5
```

### setting-para_3

**复选测试**（`para_3`）

复选示例，可以选择多个选项，保存为所选值集合。

示例：

```text
1,3
```

### setting-para_4

**单选测试**（`para_4`）

单选布尔示例，开启保存true，关闭保存false。

示例：

```text
true
```

### setting-para_5

**选单测试**（`para_5`）

下拉选择示例，从四个固定值中选择一个。

示例：

```text
select_2
```

### setting-para_6

**密码测试**（`para_6`）

密码控件示例，需要重复输入，实际控件长度为6至10字符，使用MD5转换保存。仅演示转换接口，会员密码请使用框架认证服务。

示例：

```text
DemoPass8
```

### setting-para_7

**开关测试**（`para_7`）

单项开关示例，选中提交y，未选中由配置管理按开关类型处理。

示例：

```text
y
```

### setting-para_8

**多行文本**（`para_8`）

多行文本示例，保留输入换行。

示例：

```text
第一行说明
第二行说明
```
