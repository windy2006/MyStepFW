### 字段定义转换

旧字段 PHP 文件只转换字面量，不直接执行：

```sh
php plugin/cform/convert-legacy.php /旧站/setting/1.php GB18030 > fields.json
```

支持 GB18030、GBK 和 UTF-8。将转换结果粘贴到设计器的“导入／导出”浮动层并应用，再核对默认值和双语选项。包含函数、变量引用或其他代码的定义会拒绝转换。旧记录可导出为 UTF-8 CSV 后导入；旧 PHP 模板、附件和发送历史需单独整理，不自动执行旧站扩展。

字段索引统一为1至40位，以小写字母开头，只含小写字母、数字和下划线，前后端均校验。列表左侧手柄支持鼠标／触摸拖动排序；聚焦手柄后可用上下方向键及 Home／End 调整。释放后更新设计，保存表单后前台按相同顺序显示；拖动中按 Esc 取消本次排序。
