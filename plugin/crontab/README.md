# 计划任务（crontab） <small>v2.1.0</small>

## 功能概述

管理间隔、固定日期及标准Cron任务，支持管理员受信PHP和HTTP/HTTPS URL，使用单执行锁避免同时领取。

## 安装与设置

环境为MyStepFW 2.6.3、PHP >=8.5.12且<9、mbstring。安装启用后管理地址`crontab/`；需要页面触发时绑定宿主。安装后调度停止，新任务默认停用，需明确启用任务及启动调度。

## 标准Cron

后台新建默认采用模式2，格式为“分 时 日 月 星期”，字段用空白分隔。支持星号、数字、列表、范围、步长及JAN～DEC、SUN～SAT，不区分英文大小写。星期0或7均表示周日。

```text
*/10 * * * *          每10分钟
0 9 * * MON-FRI       工作日09:00
0 0 1 * *             每月1日00:00
0 0 29 FEB *          闰年2月29日00:00
@hourly               每小时
@daily                每天00:00
@weekly               每周日00:00
@monthly              每月1日00:00
@yearly               每年1月1日00:00
```

日与星期都作具体限定时按OR匹配；其中有以星号开头的字段时两者都需满足。支持`@annually`和`@midnight`别名；不支持`@reboot`、Quartz的秒字段、问号、L/W/#等扩展。

```php
$next = plugin_crontab::nextTime(2, '0 9 * * MON-FRI', time());
echo date('Y-m-d H:i:s', $next);
```

使用框架时区；不存在的夏令时分钟跳过，标准Cron的重复钟点按实际时间可匹配两次。只计算严格晚于当前时刻的时间，不补跑所有错过的分钟。

## 间隔与固定日期

模式0为五段逗号数字“月(30天),日,时,分,覆盖天数”；例如`0,0,0,10,0`为10分钟，第五段非0时按该天数覆盖其他间隔。

模式1为“月,日,时,分,星期”；月/日0表示不限，时/分0表示字面零，星期1周日～7周六，非0时优先于月/日。`0,0,9,30,0`表示每天09:30。固定日期模式在夏令时缺失时跳过，不顺延钟点。

## 触发与运行

```sh
php /网站根/plugin/crontab/run.php
php /网站根/plugin/crontab/run.php --loop
```

CLI读取配置和启用状态，不启动完整应用会话；依赖数据库时由任务自行准备连接。生产中由服务器调度器或进程管理器触发CLI。页面end钩子为同步、访问触发，无访问时不唤醒。

插件参数`interval`为页面/CLI循环检查间隔（10～86400秒，默认120秒），`batch`为每轮任务上限（1～20，默认5）。分钟级Cron应每分钟调用CLI，或将循环检查间隔设为不超过60秒；表达式本身不会创建操作系统任务。

## 执行与结果

代码和URL同时填写时先执行代码；URL使用GET，不携带管理员凭据、不跟随跳转，读取失败或超时记为失败。PHP代码不包含开始/结束标签，在框架上下文使用`$mystep`、`$ms_setting`、`$db`、`$cache`、`$info_app`；CLI不保证服务均已初始化。

调度领取前核对任务修订、启停及停止开关，先记录下次时间，再执行；停止允许当前任务结束，不继续领取本批后续项。执行期间编辑任务，执行中的结果不会覆盖再次修改后的任务状态，日志保留revision。输出分块截取最多16000字节及4000字符，日志最多1000条。

受信PHP主动exit、无限循环、修改缓冲或分配大量内存无法由普通异常捕获保证收尾；业务副作用应自行保证幂等。后台代码导入新增记录且默认停用，其他操作采用POST/CSRF，表单使用checkForm。

数据保存在`config/plugins/crontab/state.php`，锁及原子替换保护读改写；卸载保留任务和历史。CLI与Web共用执行锁，不新增Composer依赖。

## 设置说明

安装／设置页的“填写说明”会在独立插件指南中打开本文件对应章节。所有示例均为示范值，请按实际环境填写；不要复制示例密钥作为生产凭据。配置保存在本插件的 `config.php`。

### setting-interval

**检查间隔**（`interval`）

页面触发及CLI循环两次检查之间的间隔秒数，范围10至86400，默认120。每分钟计划应配合每分钟CLI触发或不超过60秒的循环间隔。

示例：

```text
60
```

### setting-batch

**每轮任务上限**（`batch`）

每轮调度最多领取的任务数量，范围1至20，默认5。长任务较多时降低该值，避免单轮执行过久。

示例：

```text
5
```

## 管理设置

以下项目在插件自己的管理或编辑页面中维护；隐藏的操作凭证与修订字段由程序生成。

### field-name

**任务名称**（`name`）

用于任务列表及日志辨认。

示例：

```text
每日汇总
```

### field-describe

**说明**（`describe`）

记录任务用途。

示例：

```text
生成每日统计
```

### field-mode

**计划类型**（`mode`）

2标准五字段Cron；0五段间隔；1五段固定时间。

示例：

```text
2
```

### field-schedule

**执行计划**（`schedule`）

Cron按分、时、日、月、星期填写；其他类型使用逗号五段格式，详见标准Cron章节。

示例：

```text
0 9 * * MON-FRI
```

### field-expire

**截止日期**（`expire`）

YYYY-MM-DD，包含当天，留空不限制。

示例：

```text
2026-12-31
```

### field-url

**执行URL**（`url`）

以GET请求执行，不携带管理员凭据且不跟随跳转。

示例：

```text
https://example.com/jobs/report
```

### field-code

**PHP代码**（`code`）

不包含PHP开始结束标签；与URL同时填写时先执行代码。CLI环境不保证业务数据库等已初始化。

示例：

```text
echo date("Y-m-d");
```

### field-active

**启用任务**（`active`）

单条任务开关；还需要启动调度，并安排页面或CLI触发。

示例：

```text
勾选
```

### field-json

**导入JSON**（`json`）

粘贴本插件导出的JSON内容，导入会新增记录而不是覆盖；PHP任务和代码片段导入后默认停用，确认内容后再启用。

示例：

```text
{"items": []}
```
